================================================================================
                            NEXT STEPS
================================================================================

1. INSTALL DEPENDENCIES:
   pnpm install

2. START WEB APP (Development):
   cd apps/web
   pnpm dev
   → Open http://localhost:3000

3. START MOBILE APP (Development):
   cd apps/mobile
   pnpm dev

4. SHARED PACKAGE USAGE:
   Both apps can import from @bitacora/shared:
   - import { store } from '@bitacora/shared/store'

5. BUILD FOR PRODUCTION:
   pnpm build          # Build all
   pnpm -C apps/web build     # Build just web
   pnpm -C apps/mobile build  # Build just mobile

================================================================================
                        AVAILABLE COMMANDS
================================================================================

From Root:
  pnpm install                 # Install all dependencies
  pnpm dev                     # Start all dev servers
  pnpm build                   # Build all apps
  pnpm lint                    # Lint all packages
  pnpm test                    # Test all packages

Web App Specific:
  pnpm -C apps/web dev        # Start Next.js dev server
  pnpm -C apps/web build      # Build for production
  pnpm -C apps/web start      # Run production server
  pnpm -C apps/web lint       # Lint web app
  pnpm -C apps/web type-check # TypeScript check

Mobile App Specific:
  pnpm -C apps/mobile dev     # Start Expo dev server
  pnpm -C apps/mobile ios     # Run on iOS
  pnpm -C apps/mobile android # Run on Android
  pnpm -C apps/mobile web     # Run web version
