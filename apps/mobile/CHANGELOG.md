## [1.0.0] - 2026-04-22

### Added
- Initial project setup with Expo SDK 54
- React Native 0.81.5 framework
- Expo Router 6.0 for file-based navigation
- NativeWind 4.1 and TailwindCSS for styling
- Authentication flow with Email and Google OAuth
- Tab navigation system (Home, Record, Memory, Profile)
- Home screen with session list
- Recording functionality
- Memory management interface
- Profile screen
- Responsive design for iOS, Android, and Web
- Lucide React Native icons
- TypeScript configuration
- Custom button component
- Create Bitácora modal component
- Mode badge component

### Fixed
- Metro bundler ESM resolution issues with @babel/runtime
- react-native-css-interop module resolution errors

## [0.0.1] - 2026-04-20

### Added
- Project initialization
- Basic Expo app structure
- Development environment setup
